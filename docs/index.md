# COMP1011 - UX/UI Development

## Overview

For full course information [COMP 1011 - BCIT](https://www.bcit.ca/courses/ux-ui-development-comp-1011/)
<br>Course taken in **Fall 2025 term** ([outline](https://www.bcit.ca/outlines/20253047028/)) with **Jon Bantados**.

- 12 weeks, weekly labs + project + final exam  
- Final exam is accumulative, no midterm  
- Testing with classmates is mandatory  
- No class recordings, slides/resources on Learning Hub  

**Grading**  
- Quizzes: 15%  
- Weekly Labs: 25%  
- Final Exam: 25%  
- Final Project: 35%  
- Passing grade: 60%  

**Tools**  
- Recommended: Figma (industry standard)  
- Allowed: Adobe XD (not recommended)  
- Suggested books:  
  - *Don’t Make Me Think* (Steve Krug)  
  - *The Design of Everyday Things* (Don Norman)  

---

## Class Expectations
- Classes start at 6PM (Tues/Wed, depending on section)  
- Attendance is taken; both lecture + lab required  
- Webcams on if speaking (online sections)  
- Notify instructor if absent — you’re responsible for missed work  
- Expected to: collaborate, think critically, step outside comfort zone, ask questions  

**General class structure**  
Attendance → Lecture → Activity → Quiz → Break → Lab  

# Labs and Quizzes
**Labs**  
- Due weekly (or biweekly depending on schedule)  
- Work contributes to final project  
- Submit as PDF  
- Late = no feedback, grade of 0 (unless prior arrangement)  
- Labs focus: mobile/desktop app design using UX/UI practices, design decisions backed by user data  

**Quizzes**  
- Weekly, based on prior week’s content  
- Format: multiple choice, short answer, T/F, written response  
- Focus: analyzing real interfaces, applying design rules  

**Plagiarism**  
- No copying peers’ work  
- No using prebuilt app prototypes  
- No uncredited icons/images  
- No AI use on quizzes/exams
